## HR Recruitment Analytics Dashboard

## Objective
To analyze recruitment performance and streamline the hiring process
using structured MIS and analytics.

## Background
Based on real-world HR recruitment experience involving sourcing,
screening, documentation, and coordination with stakeholders.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboards

## Key Metrics Analyzed
- Applications vs Interviews vs Offers
- Time-to-Hire
- Role-wise Hiring Status
- Documentation Completion Status

## Key Insights
- Identified bottlenecks in the hiring funnel
- Improved visibility of pending documentation
- Helped optimize recruitment turnaround time

## Outcome
This project demonstrates HR analytics, reporting accuracy,
and data-driven decision-making skills.
